## 2. 各层职责

### 前端层

- **可选技术**：
    - 微信小程序：原生框架 + 微信地图组件
      
    - H5/APP：**Vue->uniapp*** 
      
    - 移动端跨平台：**Flutter** / React Native

- **实现细节**：

	- 包括三个页面：
	
		1. 用户登录页面：提示用户登录，并向后端传入用户输入信息进行比对，然后载入用户收藏信息；
		2. 用户收藏界面：显示传入的用户收藏信息；
		3. 地图渲染界面：最主要的界面，展示地图并自动切换到用户位置，用户输入地址信息后向后端传入信息，得到经纬点并渲染路径
       

---

### 后端层


#### 可选技术：

Node.js (Express / NestJS)
        
**Java (Spring Boot)**
        
Python (FastAPI / Django)
        
数据库：**MySQL** / PostgreSQL / **MongoDB**

#### 实现细节：

- **API网关**：
	- 接受前端用户信息(字符与数字的JSON包)
	- 接受前端输入位置(经纬点JSON包)
	- 接受前端定位位置(经纬点JSON包)
	- 接受建模路线信息(路线索引)

- **后端逻辑层**：
	- 在数据库内匹配搜索用户信息
	- 查找用户收藏信息
	- 将建模的路线索引打包成JSON包


#### PLAN B：

- 建模结果直接传送JSON包，无需逻辑层打包
- 建模负担加重，后端负担减轻
