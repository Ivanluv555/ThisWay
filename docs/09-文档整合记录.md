### 9.1 整合原则与结果

- 业务划分、当前技术、变量、接口、数据和模型各只有一个主说明位置；旧的“已完成”口号、重复示例、个人路径、无证据收益和空占位移除。
- 首轮正文收敛为 `docs/` 下 13 份 Markdown：按 01–10 编号，另含总索引及两个资源说明；11 保存算法原型，12 保存 Excalidraw 源图/图片/生成工具，13 保存示例数据。后续新增政策见 9.5。
- 根 README 保留项目简介与文档入口；标准政策文件仅作正文入口；LICENSE、依赖清单、业务 SQL 和 Flask 运行时 HTML 留在工程所需位置。
- 三份仅含“预留”的报告删除；没有生成或补写虚构验收结果。
- 旧文档通过 Git 历史可追溯；本目录不再复制存档整套过期正文。
