## 06 部署与验证

> 配置唯一入口：[02 开发与运行](./02-开发与运行.md)。当前阻碍：[08 项目状态](./08-项目状态与待办.md)。安全报告与处置按 [14 SECURITY](../SECURITY.md)。本文给出部署骨架，不表示生产验收已完成。

### 6.1 发布单元与先决条件

| 单元 | 准备内容 | 验证 |
| --- | --- | --- |
| MySQL | 专用账号、所需表、独立测试数据、备份 | 实际 schema 与实体一致，恢复演练完成 |
| Java | JDK 17、Maven 构建 JAR、真实配置 | `/api/locations`、`/v3/api-docs` 及错误处理 |
| FastAPI | 可复现 Python 环境、依赖、Spring 地址；爬虫另配数据库 | `/health`、`/docs`、一次预测及回读 |
| 微信小程序 | 冲突已解决、API 基址、AppID、发布域名 | 开发者工具编译、真机、登录与业务用例 |

Flask/Express 为独立原型，主链路发布不默认包含。Redis 不是当前文档定义的必选缓存组件；按实际启用的 Session/存储方案另行配置。

### 6.2 发布流程

1. 固定 Git 版本、依赖和配置清单；完成隔离环境验证，记录未完成项。
2. 备份目标数据库与上一版本产物。SQL 的 `DROP TABLE` 重建仅用于明确选择的空库，生产变更使用审查过的增量迁移。
3. 在 Java 模块执行 `mvn -DskipTests package` 形成 JAR，记录文件校验值；测试独立记录，不用跳过测试的构建冒充测试通过。
4. 将 JAR 与 FastAPI 环境部署到版本目录，由进程管理器管理，设置工作目录、环境文件、日志和重启策略。
5. 先启动 Java，再启动 FastAPI；明确是否启动模拟器与预测调度器，避免重启后默认状态与预期不一致。
6. 完成只读健康检查、隔离的写入/回读用例、真机验证后再切换流量；持续检查错误率和资源。

环境文件不要入库。systemd 的 `EnvironmentFile` 使用 `KEY=value` 格式，不要直接复用带 `export` 的 shell 脚本；日志目录需对服务账号可写。Java 与 FastAPI 分开管理，不能把只启动 Java 描述为全系统上线。

### 6.3 最小验证顺序

只读检查（默认地址可按部署调整）：

```bash
curl -f 'http://127.0.0.1:8080/api/locations'
curl -f 'http://127.0.0.1:8080/v3/api-docs'
curl -f 'http://127.0.0.1:8001/health'
curl -f 'http://127.0.0.1:8080/api/flow/history/latest'
curl -f 'http://127.0.0.1:8080/api/spot-traffic-predictions/latest'
```

写入验证仅针对隔离测试库：准备景点 → 生成历史 → 请求 `/predict?write_back=true` → 回读同一 `predictTime` 的预测和 `predictHour` 的转移 → 小程序展示。以当轮 ID/时间和字段验证，不能仅要求“数据库已有记录”或“响应含 summary”。

### 6.4 现有验证工具及其限制

| 工具 | 作用 | 当前限制 |
| --- | --- | --- |
| `devs/script/pre_deploy_check.sh` | 静态检查与构建 | 自增计数在 `set -e` 下提前退出；配置与 Wrapper 规则过期，不能直接当发布门禁 |
| `devs/script/deploy.sh` | 备份、构建、启停 Java | 变量检查不统一、依赖缺失 Wrapper；仅 Java，非全系统部署 |
| `devs/script/test_api_health.sh` | Java 核心 API | 同类计数退出问题；缺 Actuator 仍可被预期 404 判通过；不是业务验收 |
| `devs/script/test_next_destination_prediction.sh` | 预测链路 | 会写数据，含固定远程 DB 地址；需改隔离环境与结果断言 |
| `devs/script/test_next_destination_full_chain.sh` | 历史生成、预测、回读 | 会写数据，含凭据字面值和旧库名；不直接执行 |
| Java `CidiApplicationTests` | Spring 上下文加载 | 指定远程 DB 配置，非独立单元测试 |
| FastAPI `tests/smoke_test.py` | Spring ↔ DB 通路 | 固定 21 个景点/ID，写历史和预测；缺清理与隔离 |
| 旧算法 `test_models.py` | 复杂模型单元用例 | 实际依赖 NumPy，当前基础环境缺少；两套副本重复 |
| 简化模型内置示例 | 一组假设输入断言 | 只证明该示例，不覆盖模型准确性 |

### 6.5 故障定位

| 现象 | 先查 | 再查 |
| --- | --- | --- |
| 小程序编译失败 | 合并冲突与 JSON/JS 语法 | 工具导入目录和基础库 |
| 真机无法请求 | 基址是否为手机自己的 localhost | 网络可达性与域名配置 |
| 登录失败 | Mock 开关、无后缀微信变量 | JWT HS512 密钥长度、真实 code/微信响应 |
| `/crowd-index` 失败 | 客户端错误调用 `/api/flow/latest` | 修正后还需对齐 camelCase/snake_case 和时间解析 |
| 推荐空数组 | 源景点是否有当轮分流记录 | 预测是否实际写回、算法是否产生候选、数据时效 |
| 调度计数增加但无数据 | 当轮持久化回读与 warning 日志 | 写入异常是否被吞并、部分写入 |
| 后端启动失败 | 数据库、账号、`SDP`/标准变量和端口 | Maven/Java 版本及配置覆盖 |

### 6.6 发布验收与回滚

| 验收域 | 最低证据 |
| --- | --- |
| 功能 | 登录、景点/地图、搜索、文章、互动、收藏、预测的通过/失败用例及错误处理 |
| 权限 | 资源归属、管理员范围、未登录和越权请求；当前未见统一资源鉴权，需先补齐 |
| 安全 | 按 14 核对凭据、敏感响应、任务入口与测试隔离；发现问题须留有修复、处置及验证证据 |
| 数据 | 外键/唯一性、同轮回读、重复执行、模拟/实测标识、时间口径 |
| 性能 | 数据量、并发、p50/p95/p99、错误率和测试时长，保留原始结果 |
| 运维 | 重启恢复、任务状态、日志、告警、备份与恢复演练 |
| 产品资料 | 用户操作说明、隐私政策/用户协议正文与真实适用范围 |

回滚先切回上一应用版本，再按迁移兼容性决定是否恢复数据。数据库恢复可能覆盖发布后的写入，必须事先确定恢复点与业务处置。保留版本、产物校验、操作者、配置变更、验证结果和回滚记录。

正式报告按有实测结果时补入本文件或增加对应编号专题；已删除只有“预留”的软件测试、性能和模型检验文件。
