# 此地 ThisWay 产品介绍页：考察与内容方案

考察日期：2026-11-08。仓库基线：9efbd5f。本文面向后续维护介绍页的开发者与内容编辑。

## 1. 项目考察结果

产品定位为“多景区游客协调分流系统”。它结合景点与旅行内容、历史客流预测、拥挤参考和替代目的地建议，辅助游客自主选择行程，不强制分配游客。

| 检查来源 | 本次核对的事实 | 对介绍页的影响 |
| --- | --- | --- |
| `../../README.md`、`../../docs/01-项目总览.md` | 品牌为“此地 ThisWay”，主线为景点、预测、分流与内容社区 | 使用真实产品名，不虚构业务方向 |
| `../../frontend/cidi-wx/app.json`、页面目录 | 已有探索、动态、地图、分流、个人中心、搜索及详情等页面 | 将能力组织为探索、理解人潮、选择下一站 |
| `../../frontend/cidi-mobile/README.md`、`lib/main.dart`、`lib/data/cidi_repository.dart`、`lib/screens.dart` | 现有 Flutter 工程，默认本地体验，真实写入待移动端认证接入 | 页面列出移动端，但不提供虚构下载链接或声称已上架 |
| `../../backend/cidi-model/app/predictor.py` | LSTM 当前实现预测下一小时，另有分流计算与模拟历史生成 | 仅描述下一小时，不宣传连续多小时预测或准确率 |
| `../../backend/cidi-server/src/main/java/org/daiso/cidi/modules/locationtransition/controller/LocationTransitionController.java` | 存在最新一轮下一目的地查询与批量写回接口 | 介绍建议链路，不把接口存在视为验收通过 |
| `../../docs/05-模型与预测.md` | 部分拥挤输入为模板，多小时目的地展示重复最新一轮结果，优惠字段不等于实际发券 | 不宣传实时实测、六步预测、真实优惠券 |
| `../../docs/08-项目状态与待办.md` | 仍有接口、认证、数据、评估与端到端验证问题 | 保留项目进展与 FAQ 中的边界说明 |

旧文档仍有 `devs/` 路径，当前真实目录为根目录下的 `frontend/`、`backend/`、`script/`。介绍页没有照搬旧路径。旧总览未覆盖后续 Flutter 工程，故以移动端实际代码补充。未连接业务服务器、数据库或地图服务，未执行写入业务的接口。

## 2. 内容安排与网页结构

面向初次了解产品的游客与项目关注者。第一屏讲清价值，随后展示能力和操作方式，再解释原理与限制。

1. **顶部导航**：品牌、页内锚点、GitHub 仓库入口、移动端折叠菜单。
2. **首屏**：“风景值得，人潮不必”，原创山城意象插画，前往演示与原理的真实锚点按钮。
3. **认识此地**：景点探索、地图与拥挤参考、旅行社区。
4. **体验旅程**：三个可切换步骤，包含本页临时收藏、示例拥挤状态与自主选择。
5. **背后原理**：历史客流、下一小时预测、候选建议的解释。
6. **产品理念**：参考而非承诺、建议而非安排、保留旅行乐趣。
7. **项目进展**：游客端、数据与模型、后续规划，明确开发与验证中。
8. **常见问题**：产品定位、演示数据、预测范围、应用状态、完整性边界。
9. **收尾与页脚**：回到交互演示，提供 GitHub 源码与项目进展入口，引导关注及贡献；声明非实时信息、无购票与预约服务。

不使用虚构用户评价、客户标识、使用人数、增长数字、预测准确率、上线日期或空下载按钮。重庆景点名称取自移动端示例，景点状态为本页人工设置的演示值，不用于真实出行判断。

## 3. 视觉与实现约定

- 延续移动端暖白与森林绿，用低饱和金色、植物绿和衬线标题营造旅行编辑页感。
- 页面装饰使用原创 SVG 场景插画，明确标记插画而非实景。SVG 不是地图或量化图表。
- 应用图标统一使用 Lucide React。品牌使用 Lucide 的山形标识，favicon 是本地简化品牌图形。
- 动画统一使用 Motion：一次性视口入场、首屏卡片入场、步骤文案过渡及选中标记移动。不引入第二个动画库，不设置无限循环动画。
- 尊重系统减少动态效果偏好，关闭位移与滚动动画，保留完整交互。
- 桌面并列布局，平板收紧间距，手机单列。测试脚本覆盖窄屏到宽屏。
- 原生 `details/summary` 承担 FAQ；Tab 组件具备方向键、Home、End 导航；收藏按钮提供可访问名称与按下状态；移动菜单支持 Escape 与焦点恢复。
- 无后端请求、定位、遥测、外部字体或远程图片。收藏只保存在组件内存，刷新即重置。
- 独立 React + TypeScript + Vite 工程，依赖锁定。相对资源路径配置用于静态目录部署。
