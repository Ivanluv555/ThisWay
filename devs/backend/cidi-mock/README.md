
项目目标：

- 实现查询景点数据的接口（爬虫）
- 实现计算景点的游客拥挤指数的接口
- 实现预测景点游客人数的接口


将核心建模算法单独封装，方便单独测试功能



run.py 项目启动文件
/api 定义接口，实现接口
/utils 公用的函数
/spider 爬虫专用
/config.yaml 项目的配置文件
/algorithm 核心算法文件，自己做自己的，防止冲突
/data 存放静态本地数据（可能会用到）

项目运行流程：

run.py --> 启动项目

网络请求 --> api --> spider --> api --> 响应数据

网络请求 --> api --> algorithm --> api --> 响应数据
