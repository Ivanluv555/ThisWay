## 📊 数据流完整链路

```
1. 用户打开景点详情页
   ↓
2. 前端调用 getNextDestinationForecast(spotId)
   ↓
3. 发送 HTTP GET 请求
   GET /api/location-transitions/next-destinations/{spotId}?hours=6
   ↓
4. Spring Boot 接收请求
   LocationTransitionController.getNextDestinations()
   ↓
5. Service 层查询数据库
   SELECT * FROM location_transitions 
   WHERE source_location_id = {spotId}
   AND predict_hour = (最新一轮预测时间)
   ORDER BY transition_probability DESC
   ↓
6. 返回 JSON 数据
   [
     {
       "hour": "15:00",
       "transitions": [
         {"locationId": 5, "locationName": "解放碑", "ratio": 0.42, ...},
         {"locationId": 8, "locationName": "磁器口", "ratio": 0.33, ...},
         {"locationId": 12, "locationName": "南滨路", "ratio": 0.25, ...}
       ]
     },
     ...
   ]
   ↓
7. 前端渲染数据
   显示未来 6 小时的推荐目的地
```

USE cidi_db;

-- 查看转移预测数据
SELECT 
    lt.id,
    l1.title AS source_location,
    l2.title AS target_location,
    lt.predict_hour,
    lt.transition_probability,
    lt.expected_users
FROM location_transitions lt
JOIN locations l1 ON lt.source_location_id = l1.id
JOIN locations l2 ON lt.target_location_id = l2.id
ORDER BY lt.predict_hour DESC, lt.transition_probability DESC
LIMIT 10;
